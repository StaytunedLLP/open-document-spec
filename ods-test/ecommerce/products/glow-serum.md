# Glow Serum Specification

## Overview

Aura Glow's signature hydrating serum designed for all skin types.

## Key Ingredients

- 10% Niacinamide (Vitamin B3) for barrier repair and evening skin tone.
- 2% Hyaluronic Acid for multi-depth moisture retention.
- 1% Zinc PCA for sebum regulation.

See the detailed raw values in [ingredients-sheet.csv](../resources/ingredients-sheet.csv).

## Application Instructions

1. Cleanse face thoroughly.
2. Apply 3-4 drops to damp skin.
3. Gently pat until fully absorbed.
4. Follow with moisturizer.

## Safety Warning

For external use only. Avoid contact with eyes. Patch test on inner arm before first use. Discontinue if redness occurs.
